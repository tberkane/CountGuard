# CountGuard

**Audit and protect aggregate patient-count releases against reconstruction attacks.**

[![CI](https://github.com/tberkane/CountGuard/actions/workflows/ci.yml/badge.svg)](https://github.com/tberkane/CountGuard/actions/workflows/ci.yml)
[![Docs](https://img.shields.io/badge/docs-tberkane.github.io%2FCountGuard-blue)](https://tberkane.github.io/CountGuard/)
[![License: Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

Federated research networks such as Cumulus answer queries with tables of patient counts
(count cubes) and suppress small counts (e.g. below 10) to protect patients. Suppressed counts can
often be recovered exactly from the published ones. CountGuard is a Python library and
command-line tool that:

1. **runs the reconstruction attack** on a released table: integer-programming bounds on every
   suppressed count under two attacker models, plus the Bayesian reconstruction of the original
   research code;
2. **applies protections**: suppression below *k* (optionally shown as "1-9"), rounding, generalization
   (merging or dropping attributes), and differential privacy (discrete Gaussian noise via
   [OpenDP](https://opendp.org), zero-concentrated DP accounting, a consistent non-negative cube),
   composable as generalize → DP → suppress/round;
3. **measures the privacy-utility tradeoff**: re-identification risk against accuracy loss over a
   sweep of settings, with the Pareto frontier and the setting closest to a target.

It builds on the research code of the medRxiv preprint *Sharing aggregated patient counts in place of
line-level EHR data* (Chen et al., 2026), included unmodified in
[`reproduction/original/`](reproduction/original).

> **Status: early release (v0.1.0).** Every number in this repository comes from **synthetic**
> cohorts generated by `countguard.synth`. No patient data is included or used.

## Install

```bash
git clone https://github.com/tberkane/CountGuard && cd CountGuard
pip install -e .            # library + CLI (Python ≥ 3.12)
pip install -e ".[bayes]"   # + Bayesian reconstruction (cmdstanpy; needs CmdStan)
pip install -e ".[demo]"    # + the local demo page
pip install -e ".[dev]"     # + tests, ruff, mypy
```

## Quickstart

```bash
countguard synth -n 285 --seed 2 -o cohort.csv          # synthetic patient-level cohort
countguard protect cohort.csv -o cube.csv               # Cumulus-style count cube, k = 10
countguard audit cube.csv --k 10 --cohort cohort.csv    # attack it; JSON risk report
countguard protect cohort.csv -o dp.csv --dp-rho 1 --k 10 --audit   # DP, then suppress
countguard frontier cohort.csv --report frontier.json   # privacy-utility frontier
```

On this synthetic 10-variable cube (285 patients, 3,072 combinations), the attack proves the exact
size of 72 of the 82 groups of 1–9 patients from the k = 10 table, in under a second.

In Python:

```python
from countguard import Cube, DiscreteGaussian, Pipeline, Suppress, assess, kidney_cohort
from countguard.synth import KIDNEY_VARS, LEVELS

cube = Cube.from_records(kidney_cohort(285, seed=2), KIDNEY_VARS, LEVELS)
privacy, attack = assess(cube, Suppress(10).apply(cube), threat="known_support")
print(privacy.risk, privacy.certain)  # 0.42..., 72 groups proven exactly

release = Pipeline(noise=DiscreteGaussian(rho=1.0), threshold=Suppress(10)).apply(cube)
```
